Technical Terminology

Semantic HTML
The use of HTML markup to reinforce the semantics, or meaning, of the information in webpages rather than merely to define its presentation.
Version Control (Git)
A system that records changes to a file or set of files over time so that you can recall specific versions later.
Accessibility (a11y)
The practice of making websites usable by as many people as possible, including those with disabilities.
